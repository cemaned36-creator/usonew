# Подготовка импорта учебной нагрузки USO

Эта ветка добавляет модель учебной нагрузки и локальный валидатор исходного CSV. **Скрипт не подключается к БД, не меняет Neon и по умолчанию не создаёт выходные файлы.**

## Файлы

- `backend/app/models/teaching_load.py` — черновая SQLAlchemy-модель для будущей таблицы `teaching_load`.
- `backend/scripts/preview_teaching_load_import.py` — проверка и необязательная нормализация CSV.
- Данные преподавателей и занятий намеренно не коммитятся в репозиторий: они остаются локальными.

## Запуск в Windows PowerShell

Из корня клонированного репозитория:

```powershell
python backend/scripts/preview_teaching_load_import.py --detail "D:\путь\к\Список_преподавателей_и_занятийксв.csv"
```

Чтобы дополнительно создать локальные CSV для просмотра:

```powershell
python backend/scripts/preview_teaching_load_import.py --detail "D:\путь\к\Список_преподавателей_и_занятийксв.csv" --export-dir ".\backend\import_preview"
```

Файлы в `import_preview` не добавляйте в Git: они содержат персональные данные преподавателей и учебную нагрузку.

## Принятые правила

- Каждая строка исходного CSV сохраняется отдельно и получает `source_row_number`.
- Численность каждой из 12 групп временно устанавливается в 25 студентов.
- Исходная аудитория сохраняется как текст, поскольку её соответствие актуальному каталогу аудиторий ещё не проверено.
- Совместные группы сохраняются исходным текстом; автоматическое объединение строк не выполняется.
- Чётная и нечётная недели хранятся отдельно в `odd_pairs` и `even_pairs`.
- Исходник не содержит дня недели и времени начала/окончания, поэтому валидатор не создаёт записи реального недельного расписания.

## Важное предупреждение по интеграции

Пока не импортируйте `TeachingLoad` в `app/models/__init__.py` и не подключайте модель в `main.py`. Сейчас приложение вызывает `Base.metadata.create_all(bind=engine)` при старте. Регистрация новой модели может создать таблицу и на удалённой базе, если Render подключён к Neon.

Следующий этап после проверки CSV — отдельная миграция и тест на локальной/тестовой БД. Neon останется нетронутым до отдельного согласования.
